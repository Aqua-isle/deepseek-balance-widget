!!! 请勿在公用电脑上使用 !!!
本程序会把 DeepSeek API Key 加密后保存在本机（%APPDATA%\DeepSeekBalance\config.json）。
Windows 的加密只绑定"当前用户"——同一台电脑、同一个账户下的其它程序仍然可以把它解出来。
公用电脑、网吧、实验室共用机、他人可能登录的电脑，都存在 Key 泄露、余额被别人花掉的风险。
首次启动会弹一次警告，点「我已了解，继续使用」才会继续。
DeepSeek 余额挂件 —— 免安装版
==============================

【怎么用】
1. 把 DeepSeekBalance.exe 拷到任意位置（桌面、D 盘都行），双击运行。
2. 第一次运行会出现一张小卡片，右键 →「修改 API Key…」，
   把 platform.deepseek.com 生成的 Key 粘进去，点「验证并保存」。
3. 想开机自启：右键 →「开机自启」。
4. 想跟着 DSH 一起开：右键 →「跟随 DSH 启动」。

【两个版本，选一个就行】
- DeepSeekBalance.exe          单文件，12 MB，拷一个文件就能用（推荐）。
- DeepSeekBalance-portable\    文件夹版，25 MB，启动更快，整个文件夹一起拷。
   如果单文件版被杀毒软件拦住，或者系统临时目录不可写，用这个文件夹版。

【Key 存在哪里】
%APPDATA%\DeepSeekBalance\config.json，用 Windows DPAPI 加密，
只有当前 Windows 用户能解开。
软件里**没有任何内置 Key**，换台电脑必须重新填；
把 config.json 拷到别的电脑也解不开（DPAPI 绑定用户和机器）。

【系统要求】
Windows 10 / 11，64 位。不需要安装 Python。

【第一次运行提示"Windows 已保护你的电脑"】
exe 没有数字签名，点「更多信息」→「仍要运行」即可。

【卸载】
退出挂件（右键 →「退出」）→ 删掉 exe / 文件夹 → 删掉 %APPDATA%\DeepSeekBalance。
如果开过机自启，先在菜单里取消勾选。

【如果双击时被 Windows 拦住】
- 提示"Windows 已保护你的电脑"：这是 SmartScreen 对"从网上下载的未签名程序"的常规检查。
  点「更多信息」→「仍要运行」即可。
- 提示找不到运行权限 / 直接被删：多半是杀毒软件把单文件壳误判了，改用 DeepSeekBalance-portable 文件夹版。
- 想彻底不弹：右键文件 →「属性」→ 最下面勾上「解除锁定」→「确定」，再运行。
- 校验：本文件同目录可执行
  Get-FileHash .\DeepSeekBalance.exe -Algorithm SHA256
  和发布者给的哈希对一下，一致再运行。
【被强行关闭后怎么自动回来】
菜单 →「跟随 DSH 启动」和「强制关闭后自动恢复」两个都打开（推荐）。
后者会注册一个每 5 分钟运行一次的计划任务：即使挂件被任务管理器/清理工具强杀，
最多 5 分钟自己回来。不需要管理员权限，只在登录状态下运行。
不想用了：再点一次菜单项即可删除。
（单文件版每次触发都要解压，长期挂着建议用文件夹版。）
